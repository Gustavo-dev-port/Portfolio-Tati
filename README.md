## 🌐 Sobre o Projeto

O projeto consiste no desenvolvimento de um website de portfólio para uma profissional da área de UI/UX.

A proposta foi criar uma interface moderna, organizada e responsiva, permitindo apresentar projetos de forma visualmente atrativa e facilitar a navegação entre os trabalhos.

O projeto também foi utilizado para aplicar conceitos de desenvolvimento frontend moderno, componentização, tipagem com TypeScript e organização de interfaces responsivas.

---

## 🎯 Objetivos

- Criar um portfólio profissional para apresentação de projetos
- Organizar os trabalhos de forma visual e intuitiva
- Desenvolver uma interface responsiva
- Aplicar conceitos de UI/UX no desenvolvimento
- Trabalhar com TypeScript em uma aplicação React
- Utilizar componentes reutilizáveis
- Preparar a aplicação para publicação em produção
